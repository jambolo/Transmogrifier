# Naming decision

## Current name

**Transmogrifier** remains the product name. On October 19, 2026, the owner decided: “Keep ‘Transmogrifier’. I'll think of a better name later.” No rename is authorized or implemented.

Use title case in prose and the supplied wordmark in artwork. Do not abbreviate it to an invented nickname. Pair the name with **“Little apps. For right now.”** on first encounters so the unfamiliar word does not have to explain the product by itself.

Optional pronunciation help for presenters: **trans-MOG-ruh-fy-er**. Do not make users learn or explain the word before they can use the product.

## Creative independence

Give the name a new visual and verbal context: useful app tiles, everyday situations, contemporary typography, and citrus color. Avoid borrowed characters, quotations, panels, costumes, character pairings, distinctive lettering, or transformation-box imagery from existing entertainment properties.

The assets in this package do not use comic references. Retaining a word does not establish trademark clearance. This package makes no claim that the product name, tagline, symbol, or future alternatives are legally available.

## Criteria for a future name

A replacement should be easy to hear, say, type, and remember; feel adult and playful; and suggest useful small creations without requiring AI knowledge. It should work for apps someone keeps as well as apps someone uses once. Avoid promising instant results, automatic disappearance, or free service.

The symbol, colors, illustration, and message hierarchy are intentionally independent of the current word. A future approved name can replace the wordmark and copy while preserving the visual system. The owner retains the naming decision.
