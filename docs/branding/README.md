# Transmogrifier branding

**Little apps. For right now.**

A bright, witty identity for adults making small apps for everyday moments. The owner retained **Transmogrifier**; no replacement name is approved. Brand sources and review assets live here. The identity is now applied to the Android app; see the [app integration record](08-app-integration.md).

Start with the [visual brand book](brand-preview.html), which opens locally and includes a light/dark UI concept toggle. [Desktop preview](previews/brand-desktop.png) and [phone preview](previews/brand-mobile.png) provide static views.

## Assets

Editable SVG logos and icons; outlined vector wordmarks; PNG exports; Android adaptive-icon resource drafts; an original campaign illustration; social and feature graphics; bundled fonts and licenses; CSS/JSON design tokens; and reusable copy in plain text and JSON.

The UI mockup and campaign scorekeeper are labeled concepts. Current-build copy discloses the Claude API key and usage costs. “For right now” means short-lived usefulness; apps remain until manually deleted.

The identity is a creative proposal. Trademark, domain, and handle availability have not been established. No comic-derived imagery or references appear in consumer-facing assets.
