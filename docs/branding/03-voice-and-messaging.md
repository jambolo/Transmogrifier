# Voice and messaging

## Message order

Lead with the small thing someone wants to do. Explain that they describe an app in everyday words. Show a result they can open and change. Put setup and payment facts beside the action that needs them.

| Level | Copy |
| --- | --- |
| Tagline | Little apps. For right now. |
| Descriptor | A little app maker for everyday life. |
| Core explanation | Describe a little app, try it on your phone, and ask for changes. Keep it while it helps. |
| Campaign line | Make it. Use it. Move on. |
| Lifecycle clarification | Your apps stay until you delete them. |

Use one main line per surface. A paragraph containing every slogan sounds like an advertisement for itself.

## Voice rules

| Trait | Write this way | Example |
| --- | --- | --- |
| Direct | Name the action and the result | “Describe the app you need.” |
| Warm | Invite without praising routine actions | “Start with something small.” |
| Witty | Find humor in everyday situations | “An app for tonight's very serious board game.” |
| Honest | Explain a limit without dramatizing it | “This version needs a Claude API key.” |
| Unfussy | Prefer ordinary verbs | “Make,” “open,” “change,” “keep,” “delete” |

Sentence case. American spelling. Short paragraphs. Contractions are welcome. Use exclamation points sparingly. Avoid baby talk, forced excitement, sarcasm, “ta-da” after every action, and claims of magic.

## Tone by situation

| Situation | Tone | Example |
| --- | --- | --- |
| Discovery | Most playful | “Tonight needs a scorekeeper.” |
| First use | Calm encouragement | “What would make today a little easier?” |
| Waiting | Specific, factual | “Making your app…” |
| Completion | Brief and useful | “Ready to try.” |
| Failure | Calm and actionable | “The connection was interrupted. Check your internet connection, then continue.” |
| Cost | Literal | “Your AI provider charges for creating and changing apps.” |
| Deletion | Literal | “This can't be undone.” |

Never make jokes about lost data, unwanted charges, privacy, or an error. Do not imply a user's information is safe or preserved unless that particular state confirms it.

## Vocabulary

| Internal term | Default public wording |
| --- | --- |
| Project | App |
| Prompt | Description or request |
| Generate | Make |
| Regenerate / iterate | Try again / change |
| Execute / run | Open app |
| LLM | AI service; name the provider when needed |
| Workspace | The app's editing screen; omit a label where context is enough |
| Console | Error details |
| Tool iterations | Steps per request, with an explanation in advanced settings |
| Tokens | Usage units, with “tokens” retained in technical details |
| API key | API key, immediately explained as a connection key from the AI provider |

Do not rename technical concepts so thoroughly that support instructions become impossible to follow. “API key” belongs in setup because users must find it in another service. Explain it once; avoid it in the headline.

## Before and after

| Avoid | Prefer |
| --- | --- |
| “Unleash the power of agentic AI.” | “Make a scorekeeper for tonight.” |
| “Build anything instantly.” | “Describe a small app you'd like to try.” |
| “No technical setup. Ever.” | “No coding needed. This early version requires a Claude API key.” |
| “Your app is perfect!” | “Ready to try.” |
| “Oopsie! Your masterpiece vanished.” | “This app couldn't be opened.” |
| “Your data never leaves your phone.” | “Your descriptions and relevant app context are sent to your AI provider when you create or change an app.” |
| “Self-destructing apps.” | “Keep it while it helps. Delete it when you're done.” |

## Claim discipline

Use “AI” in explanations of how generation works and where information goes. Do not make it the product's personality. Never claim instant results, universal app capabilities, a guaranteed fix, automatic deletion, free generation, verified output, private-on-device generation, or live collaboration.

The product can be quick to use without advertising an unmeasured completion time. “Quick” must describe intent or a demonstrated workflow, not a service-level promise.
